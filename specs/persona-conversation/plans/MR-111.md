## Design
- `useQuery(["summary", personId])` calls `ConversationsService.readSummary`. A 404 is turned into `null` (the normal "nothing kept yet" case), so it shows an empty state and no error toast. Other errors show a generic alert, never server text.
- The panel shows only the caller's note: the API route is `/persons/{id}/summary` and the caller comes from the token, so nothing in the UI can name another user.
- "Delete note" opens a confirm dialog (same pattern as `EndChat`), calls `deleteSummary`, then writes `null` into the query cache at once and invalidates the query. `gcTime: 0` drops the text when the panel unmounts. No storage and no logging (NFR-8).

## Deviation from the ticket
The ticket also asks for the panel "on the person's page for members". Members have no person page (they only get the chat, and the "Shared with me" list is MR-113), so the panel is mounted in the chat only, which every member reaches. Noted in the ticket's Questions.
