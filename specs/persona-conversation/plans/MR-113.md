## Design
- **Invite form:** `react-hook-form` + `zod`; `adult_confirmed` is `z.literal(true)` like the API's `Literal[True]`, and Invite stays disabled until the box is ticked (AC-15.1). The dialog shows the API's one answer verbatim for any email, so it never says whether an account exists (AC-15.2).
- **Members:** `readMembers` (owner only), each with a Revoke that first says the chat ends and the summary is deleted, then calls `revokeMember` (AC-15.3). Known limit, as the ticket notes: this list does show which invited emails had accounts.
- **Shared with me:** `readSharedPersons` with `gcTime: 0`, so it asks again on every visit and a revoked person is gone (AC-15.4, AC-15.5); each entry links to `/chat/$personId`. A chat left open already shows "You no longer have access" from MR-110 (AC-15.5).
