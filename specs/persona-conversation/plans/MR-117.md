## Design
- `PersonSelect` (new): the owner's people from the shared `["persons"]` query plus "No person"; exports the `NO_PERSON` sentinel that `LinkPerson` now reuses.
- Both forms get a `person_id` field. Add: create, then link if a person was chosen. Edit: update, then link only if the choice changed. The label gets `htmlFor` so the select is reachable by its name.
- Linking stays on the existing endpoint, so ownership checks and the person-name rule are not duplicated. A failed link after a successful save shows a toast and keeps the memory.
