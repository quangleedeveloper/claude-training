## What to build
- `LLMClient.stream_answer(system, messages) -> Iterator[str]` on the protocol and on `OllamaClient` (Ollama chat with `stream: true`), with the same error translation as `answer` (`LLMError`, generic text).
- `FakeLLMClient.stream_answer` in `app/core/fake_ai.py`: yields canned chunks and counts calls, so tests can assert "no model call" (AC-6.2).
- `scripts/measure_persona_latency.py`: sends N prompts of a realistic size (synthetic text from `fixtures/`) and prints p50/p90 time to first chunk and to the end.

## Files
`app/core/llm.py`, `app/core/fake_ai.py`, `tests/utils/llm.py`, `tests/core/test_llm_stream.py`, `backend/scripts/measure_persona_latency.py`. Stay inside these so tickets can run in parallel worktrees; if you need another file, ask below first.

## Notes
- Run the script on the demo machine and post the numbers in this ticket's Questions. If p90 first chunk is over 3 s, the tech lead decides on model or hardware (spec: Areas of concern); a model change reruns the grounding evals before and after.
- Never point the script or tests at a hosted API (memorial-privacy rule 1).
