## What to build
- A "What we talked about" panel on the chat screen (MR-110) and on the person's page for members, showing the caller's own summary from `GET /persons/{id}/summary`.
- Empty state (the API answers 404) that says nothing is kept yet.
- A delete button with a confirm dialog, calling `DELETE /persons/{id}/summary`, then showing the empty state.
- The panel never shows or asks for anyone else's summary: there is no way to name one.

## Files
`frontend/src/components/Chat/RecallPanel.tsx` (new), the chat route from MR-110 (one mount point), `frontend/tests/recall.spec.ts`. Do not hand-edit `src/client/`. Stay inside these; if you need another file, ask below first.

## Notes
- A 404 from `GET …/summary` is the normal "nothing yet" case, not an error toast.
- The summary can hold what a member said about themselves: no logging, no storage (NFR-8), and it is cleared from the query cache on delete.
- Seed a summary for the e2e through the API (end a conversation that had a message, with `AI_BACKEND=fake`).
