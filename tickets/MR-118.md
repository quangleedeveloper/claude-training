## What to build
- In Add Memory and Edit Memory, the "Memory" text area becomes a rich-text editor with a toolbar: bold, italic, heading, bulleted list, numbered list, quote.
- The text is saved as **Markdown** in the existing `content` field. No API, model or migration change; the 5000-character limit now counts the Markdown marks.
- Older plain-text memories open in the editor as they are.
- The Memories table shows the words without the Markdown marks.

## Files
`frontend/src/components/Memories/MemoryEditor.tsx` (new), `AddMemory.tsx`, `EditMemory.tsx`, `columns.tsx`, `frontend/src/lib/markdown.ts` (new), `frontend/package.json` and `bun.lock` (Tiptap: `@tiptap/react`, `@tiptap/pm`, `@tiptap/starter-kit`, `@tiptap/markdown`), `frontend/tests/memories.spec.ts` and the specs that located the field by its old label.

## Notes
- The AI (extraction, search, persona) reads `content` as Markdown text. It stays data, never instructions (prompts only in `app/core/prompt.py`).
- Only the marks the toolbar offers are allowed: no links, images, code, strike or underline. No HTML is stored or rendered from user text.
- New dependencies: confirm the choice of Tiptap with the code owner.

## Done when
- Playwright: the editor shows a toolbar; bold and a list survive save and reopen; the table shows plain words; an empty memory is refused; an older plain-text memory opens unchanged
- `bun run lint` is clean and the build type-checks
- Reviewed and approved by a code owner
