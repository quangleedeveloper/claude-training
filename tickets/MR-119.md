# MR-119: The note kept after a chat invents things; uncited replies list sources

spec: FR-14 (the note), FR-13 AC-13.4 (sources) · size: S
context: intent/persona-conversation.md, specs/persona-conversation/spec.md
brief: found while testing "Talk with person" in a browser on 2026-10-30 with the real local model (`llama3.1`); the user asked to fix both
status: implemented on `fix/summary-hallucination-and-uncited-sources`, in review
depends on: MR-106, MR-110
owner: _unassigned_

## What went wrong
1. After a chat about apple pie and football, "What we talked about" said the member had mentioned a garden, a stressful job, growing kids and a favourite travel destination. None was said. The summary prompt asked for "what the family member shared about themselves (their feelings, plans, family)" and showed the model the AI's replies too, so a small local model filled the gaps (and, with other transcripts, wrote extra turns of the dialogue).
2. A reply the model gave without citing a memory ("I don't remember.") still listed all the memories it had been shown under it, next to the note "This reply is not backed by a memory."

## What changed
- The summary prompt (`app/core/prompt.py`) now gets only the family member's own messages, one sentence per message, with "never add a detail, feeling, plan, person, place or event that is not written" and one example. The AI's replies and the opening notice are no longer sent.
- Output that continues the dialogue (lines starting "Family member:" or "AI:") is dropped: the chat still ends, no note is kept.
- A reply with `done.uncited` lists no sources (AC-13.4 updated).

## Notes
- Checked against the real model with three synthetic transcripts (nothing about themselves shared; feelings and a plan shared; an instruction to say something untrue): the notes only restate the messages. A prompt cannot guarantee this, so the dialogue check is a backstop, not a proof.
- Notes already stored from before this change can still hold invented text. The member can delete theirs from the chat screen; there is no migration that clears them.
- With a previous note, the model may keep only the new sentences ("keep what still matters" is unchanged); the cap stays at 2000 characters.
