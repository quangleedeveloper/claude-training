## What to build
- Tool `ask_memory(person_id, question)`: the caller must be the person's owner or a member; superusers get no extra access. `question` is 1 to 500 characters.
- Retrieval is `search_persona` (confirmed or corrected items, not rejected, from memories linked to that person, filtered in SQL). Give `build_ask_graph` its retrieval step as a parameter instead of copying the graph, so grade, generate and the fixed `NO_ANSWER` stay shared. The existing `/search/ask` behaviour must not change.
- Neutral third-person helper (`ANSWER_SYSTEM_PROMPT`). No persona voice, no AI-recreation notice, no persona prompt text.
- Return `{answer, sources}` with `[n]` citations that map to `sources`, and no source that was not in the prompt. Nothing clearing `MIN_RELEVANCE_SCORE` returns `NO_ANSWER` with no sources and no model call.
- A model failure returns the generic "The assistant could not answer right now", never the model's error text.
