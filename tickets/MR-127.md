## What to build
- The runner (`backend/scripts/run_grounding_evals.py`) reads the new optional case fields `spec` and `via` (see `evals/grounding/README.md`). A case with `via: "mcp"` is driven through the `ask_memory` tool as the fixture user in `as`, with the real local model, and scored with the same rules: fallback, cites, `not_cites`, `must_include`, `must_not_include`, and the invented-memory check (a `must_not_include` hit, or a cited source not in the fixture).
- The validator (`backend/scripts/validate_evals.py`) checks `from` against the spec named in `spec` (default `persona-conversation`) instead of only the persona spec, and still requires every case in `qa/test-matrix.md`.
- The report lists MCP cases separately and shows zero invented memories before merge.
- Cases `G-118` to `G-127` are already in `evals/grounding/` (from the test matrix). Add or change a case only through a question below.
